# 沙箱与安全边界

## 1. 需要保护的资产

- 用户代码和私有仓库凭证。
- 平台 LLM、数据库、对象存储和云凭证。
- 其他租户的任务、文件、日志和产物。
- 宿主机、容器运行时和内部网络。
- 平台配额、费用和可用性。

## 2. 信任边界

- 用户自然语言任务不可信。
- 仓库内容、README、依赖和脚本不可信。
- LLM 输出不可信，必须经过结构化校验和策略授权。
- 沙箱内命令及其输出不可信。
- 平台控制面、策略和短期凭证属于高信任区域。

## 3. P0 最低控制

### 进程和容器

- 每个 attempt 使用新的隔离环境。
- 非 root 用户，禁用 privileged，移除非必要 capabilities。
- 使用只读根文件系统和独立可写工作目录。
- 不挂载宿主目录、Docker socket或控制面凭证。
- 设置 CPU、内存、PID、磁盘和总执行时间限制。
- 取消或结束时终止完整进程树并销毁环境。

### 文件系统

- 所有路径解析到任务工作区内的规范绝对路径。
- 在打开文件前再次检查真实路径，防止符号链接逃逸。
- 限制单文件大小、总写入量和工具输出大小。
- 禁止访问 `/proc`、宿主设备和非任务挂载。

### 网络

- 默认拒绝所有出站访问。
- 仓库拉取在受控准备阶段完成，不向用户命令暴露凭证。
- 如未来允许联网，必须通过出口代理、域名白名单和审计。
- 显式阻止云元数据、RFC1918 内网和控制面地址。

### 凭证

- 使用短期、最小权限、按任务注入的凭证。
- 凭证不进入 LLM 输入、普通环境转储、日志或产物。
- 工具输出进入事件或模型上下文前执行敏感信息清理。
- 任务结束后撤销或失效凭证。

### 工具与 Agent

- 工具参数使用 JSON Schema 或等价机制校验。
- 为每个工具定义权限、超时、输出限制和审计字段。
- 命令工具在沙箱内执行，不在宿主机拼接执行模型输出。
- 检测重复工具调用和无进展循环。
- 高风险写操作预留人工审批，不纳入默认 P0 自主权限。

## 4. 重点威胁测试

- `../../` 和绝对路径穿越。
- 工作区内符号链接指向工作区外。
- fork bomb、无限循环、后台进程和大量子进程。
- 持续写磁盘、无限标准输出和超大文件。
- README Prompt Injection 诱导读取密钥或访问网络。
- 访问 `169.254.169.254`、localhost 服务和内部网段。
- 从环境变量、进程信息和配置文件读取秘密。
- 任务取消后残留进程或未销毁沙箱。
- 重复消息导致任务或产物重复提交。

## 5. MVP 明确限制

Docker 容器提供资源与命名空间隔离，但不能作为执行任意高风险不可信代码的最终安全边界。生产化需要评估 gVisor、Kata Containers、Firecracker、独立节点池和更严格的内核策略。

## 6. 安全完成条件

- 所有 P0 控制有配置或代码证据。
- 路径、资源、网络、凭证和清理均有自动化测试。
- Critical 与 High 风险在交付前关闭，或由用户明确接受。
- 已知限制写入 README 和演示说明。
