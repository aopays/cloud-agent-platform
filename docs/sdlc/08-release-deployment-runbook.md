# 发布、部署与回滚手册

- 文档版本：1.0
- 状态：`DRAFT`
- 原则：不可变构建、环境晋级、渐进发布、先兼容后迁移、可验证回滚

## 1. 环境分层

- Local：离线 Demo 和可信本地执行，不处理真实客户数据。
- CI：短生命周期依赖服务、Mock 模型、自动化测试和安全扫描。
- Development：共享开发，允许快速变更，不作为验收证据。
- Staging：与生产版本和策略同构，使用合成数据，执行发布候选验证。
- Production：严格 OIDC、强隔离、受控网络、审计、SLO 和值守。
- Security Lab：与其他环境隔离，用于恶意仓库和逃逸测试。

配置采用同一镜像、不同外部配置；不得为某环境维护代码分支。生产禁止 `SANDBOX_BACKEND=local`、开发 Token、
Demo Provider 和内存持久化。

## 2. CI 流水线

1. 校验提交和变更范围。
2. Ruff format/check、mypy、compileall。
3. 单元、组件、集成、E2E 和 security marker。
4. OpenAPI/事件 Schema 兼容性和迁移前后测试。
5. SAST、SCA、secret、license、SBOM、IaC 和容器扫描。
6. 构建不可变镜像，记录源码版本、依赖和 provenance。
7. 使用 KMS-backed key 签名镜像并推送受控 registry。
8. 部署临时环境执行 smoke、策略和基础性能测试。

只有同一个构建产物可以从 Staging 晋级到 Production，禁止上线前重新构建。

## 3. CD 与灰度

发布顺序：数据库兼容迁移 → 控制面 canary → Worker canary → Web/SDK → 流量逐步扩大。灰度比例建议
5% → 25% → 50% → 100%，每阶段至少覆盖一个典型高峰周期。观察 API 错误率、P95、排队、任务成功、取消、
Sandbox 创建/清理、模型错误、成本和安全拒绝。

停止灰度条件包括：错误预算快速消耗、跨租户/授权异常、任务成功率下降超过 3 个百分点、P95 恶化 30%、孤儿
Sandbox 增长、成本翻倍或任何 Critical 安全信号。

## 4. 数据库迁移

采用 expand/migrate/contract：先增加向后兼容字段和表；新旧代码双读/双写或后台回填；验证行数、哈希和失败率；
切换读取；观察稳定后在后续版本删除旧结构。长迁移异步分批，不在启动时锁大表。每个迁移有预估时长、锁影响、
磁盘增长、恢复点和回滚/前滚策略。

状态枚举、事件语义和非空字段不能在同一发布中破坏旧 Worker。数据库回滚不等于应用回滚，必须评估新写入数据
是否仍能被旧版本理解。

## 5. Feature Flag

高风险能力按 tenant、用户、任务类型和百分比启用。Flag 有 owner、创建时间、默认值、指标、到期日和删除任务。
Flag 关闭必须能够阻止新工作流进入，同时不破坏已经运行的工作流。安全策略不能被普通产品 Flag 绕过。

## 6. 发布前清单

- 版本、范围、变更单、负责人和维护窗口确认。
- G4 所需测试、安全、性能、UAT 和例外审批完成。
- 数据迁移、备份、恢复点和回滚命令演练。
- Dashboard、告警、Runbook、值班人和沟通渠道就绪。
- 模型/Prompt/策略/镜像版本冻结，供应商配额充足。
- 租户通知、发布说明和已知限制完成。
- 上一稳定版本镜像和配置可立即恢复。

## 7. 回滚策略

- 应用异常：停止扩量，路由回上一版本，保留失败请求证据。
- Worker 异常：停止领取新任务，让安全节点排空；必要时取消并由恢复扫描接管。
- 迁移异常：优先前滚修复；只有确认数据兼容时才回退应用/数据库。
- Prompt/模型异常：通过 version pin 和路由 Flag 回到上一基线。
- 安全事件：立即关闭相关工具、出口或租户，撤销凭证并执行事件 Runbook。

回滚后必须验证健康、核心 smoke、队列增长、运行任务、产物和审计；不能只确认 Pod Ready。

## 8. 发布后验证

发布后 15 分钟、1 小时、24 小时检查 SLI、业务成功率、错误分布、成本、孤儿资源和客户反馈。稳定性窗口结束后
关闭变更单，更新版本文档和基线；若发生回滚或 Sev1/Sev2，在 5 个工作日内完成复盘。

## 9. 当前本地启动

当前演示环境使用 Uvicorn 和开发 Token，仅用于本机验证：

```powershell
$env:APP_ENV="development"
$env:SANDBOX_BACKEND="local"
.\.venv\Scripts\python.exe -m uvicorn src.main:app --host 127.0.0.1 --port 8001
```

此命令不是生产部署方案。生产需独立 API/Worker、OIDC、PostgreSQL、工作流、对象存储、Secret Manager 和受支持的
隔离运行时。
