# 运维、SRE 与灾备手册

- 文档版本：1.0
- 状态：`DRAFT`
- 目标：在可测量的可靠性和成本边界内运营平台

## 1. 服务等级目标

- API Availability：月度 99.9%。
- Task Create Latency：P95 < 500ms。
- Task Start Delay：有容量时 95% < 30s。
- Running Cancellation：95% < 5s，99% < 15s。
- Supported Task Success：Beta 真实任务 ≥ 95%。
- Event Durability：已确认写入的事件不丢失。
- Artifact Availability：有效保留期内 99.9%。

每个 SLO 有 SLI 查询、数据源、窗口、排除规则和 owner。错误预算用于控制发布速度，不用于降低安全要求。

## 2. 关键指标

- API：请求数、状态码、P50/P95/P99、限流和认证失败。
- Workflow：创建、排队、运行、终态、重试、死信、租约丢失和恢复。
- Runtime：turn、token、模型延迟、供应商错误、工具次数、无进展和预算耗尽。
- Sandbox：创建/销毁时延、资源峰值、策略拒绝、孤儿进程/目录和清理失败。
- Storage：连接、锁、慢查询、复制延迟、对象错误、容量和生命周期删除。
- Business：需求会话完成、质量通过、人工接管、报告下载和用户修改率。
- Cost：模型、计算、存储和网络按 tenant/task/model 归因。

## 3. 告警策略

告警必须可行动并链接 Runbook。建议采用多窗口错误预算 burn rate，避免仅凭瞬时阈值。立即分页：跨租户/凭证泄漏、
Sandbox 逃逸、API 大面积不可用、队列无法消费、数据损坏和对象不可下载。工作时间处理：成本异常、容量趋势、
单供应商错误、清理重试升高和评测质量回退。

## 4. Runbook

### 队列积压

确认是流量、Worker 容量、模型限额、数据库还是沙箱启动导致；停止非关键租户；扩 Worker；检查租约和死信；
不要通过无限延长可见性掩盖卡死任务。恢复后回放安全消息并验证重复幂等。

### 模型供应商故障

验证错误类型和区域；启用有限重试/备用模型；对质量敏感任务进入等待而不是静默降级；保护预算和速率限制；
记录受影响 task。恢复后不能自动重复有副作用工具。

### 孤儿 Sandbox

停止相关 Worker 领取；根据 control-plane 记录枚举 orphan；先撤销网络和凭证，再终止资源；保存最小取证；运行
cleanup reconciler；持续失败升级安全事件。禁止按模糊路径递归删除。

### 数据库故障

切换只读/降级策略；停止新任务和状态写入；验证主从和恢复点；由数据库负责人执行 failover；恢复后运行 outbox、
租约和状态一致性扫描。

## 5. 备份与恢复

- PostgreSQL：连续 WAL + 每日全量，跨账户/区域加密存储。
- Object Store：版本、生命周期、复制按客户等级配置。
- 配置/策略/Prompt：Git 和制品库版本化，不依赖运行节点本地文件。
- Secret：由 Vault/KMS 自身备份与恢复策略管理，不导出明文。

每季度执行恢复演练：恢复到隔离环境；验证 schema、行数、事件连续性、产物哈希和授权；记录实际 RPO/RTO。未验证
的备份不能视为可恢复。

## 6. 容量与弹性

Worker 按排队时延、任务类型和资源请求扩缩，不只看 CPU。模型供应商配额、Sandbox 冷启动和数据库连接通常先于
CPU 成为瓶颈。按只读分析、代码构建和高隔离任务建立独立池，防止大任务饿死小任务。设置租户并发、任务预算、
日/月 token 和产物容量上限。

## 7. 成本治理

每个任务记录模型 input/output token、模型价格版本、Sandbox 秒、CPU/内存、存储和网络。预算在创建时预检，运行时
持续扣减，接近阈值产生事件，达到硬限额终止。缓存只能用于租户内、策略一致、无敏感泄漏的确定性结果。每月分析
单位成功任务成本、失败浪费、重试成本和模型路由收益。

## 8. 值班与事件管理

- Sev1：安全边界、跨租户、全站或数据破坏；立即响应并启动 Incident Commander。
- Sev2：核心流程大面积降级或 SLO 严重消耗；15 分钟内响应。
- Sev3：局部功能、单租户或有绕行问题；工作时间处理。

事件时间线记录事实、决策和证据，不记录猜测。恢复优先于根因；事后复盘无责但有明确 action owner、截止时间和
验证方式。

## 9. 生命周期与退役

服务、API、模型、Prompt、工具和沙箱镜像都有 owner 和生命周期。弃用提前公告，提供迁移、使用量监控和明确
sunset 日期。租户退出时停止新任务、处理运行任务、导出允许数据、撤销凭证、删除数据并保留合规要求的最小审计。
