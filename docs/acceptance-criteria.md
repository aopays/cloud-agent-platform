# P0 验收标准

## 1. 端到端主流程

- 可以提交自然语言任务和一个可访问的 Git 仓库。
- API 返回稳定的 task ID，重复幂等请求不会创建重复任务。
- Worker 能准备独立工作区并运行 Agent Loop。
- Agent 能使用文件搜索或读取工具完成“查找 TODO 并生成报告”的示例。
- 最终任务进入 `SUCCEEDED`，报告可以通过 API 获取。
- 任务结束后对应沙箱和工作进程被清理。

## 2. 状态与事件

- 任务状态只发生合法转换，终态不可逆。
- 每个事件包含 task ID、attempt ID、单调递增 sequence、类型和时间戳。
- 工具调用记录工具名、持续时间、结果状态和截断标记。
- 不存储模型私有思维链，只保存可公开行动摘要。

## 3. 取消、超时和失败

- `QUEUED` 和 `RUNNING` 任务都可以取消。
- 取消运行任务会终止沙箱内的进程树。
- 单命令超时不会导致 Worker 永久阻塞。
- 总任务超时后状态为 `TIMED_OUT`，并执行清理。
- LLM 暂时性错误按策略有限重试；业务错误不盲目重试。
- Worker 重复收到同一 attempt 时不会重复提交终态或重复产物。

## 4. 安全

- 沙箱内进程不是 root。
- CPU、内存、PID、磁盘和运行时间限制可验证。
- 默认不能访问公网和云元数据地址。
- 沙箱不能访问宿主 Docker socket。
- 文件工具拒绝工作区外路径、`..` 穿越和危险符号链接。
- 日志、事件和产物中不出现注入的凭证。

## 5. 工程质量

- 提供一键启动或清晰的本地启动步骤。
- 单元测试覆盖状态机、预算、策略和主要工具。
- 集成测试覆盖 API 到 Worker 的任务生命周期。
- 端到端测试覆盖至少一个成功、取消、超时和策略拒绝场景。
- README 说明架构、运行方法、已实现范围和已知限制。
- 所有测试结果可复现，不以截图代替命令和退出码。

## 6. 演示脚本

1. 启动平台。
2. 提交包含 TODO 的示例仓库。
3. 实时观察任务状态和工具事件。
4. 下载或查看生成报告。
5. 再提交长任务并演示取消。
6. 展示资源限制、默认禁网和路径穿越测试。
