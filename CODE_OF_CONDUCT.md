# Code of Conduct

Be respectful, constructive, and specific. Assume good intent while evaluating technical
claims by evidence. Harassment, discrimination, personal attacks, threats, doxxing, and
publication of private data or credentials are not acceptable.

Maintainers may edit or remove abusive content and restrict participation when necessary.
Report conduct concerns privately to the repository owner. Security reports must follow
[`SECURITY.md`](SECURITY.md), not public discussions.
